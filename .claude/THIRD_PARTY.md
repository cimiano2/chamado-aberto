# Componentes de terceiros em .claude/

Os agentes e skills abaixo foram **adaptados** (traduzidos, reduzidos e ajustados ao
Chamado Aberto) a partir do projeto [Claude Code Game Studios](https://github.com/Donchitos/Claude-Code-Game-Studios)
(commit abc0de7):

- `agents/godot-gdscript-specialist.md`
- `agents/accessibility-specialist.md`
- `agents/qa-tester.md`
- `agents/game-designer.md`
- `skills/balance-check/SKILL.md`
- `skills/playtest-report/SKILL.md`
